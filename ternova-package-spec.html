터노바 패키지 디자인 스펙 (애프터폼 전달용)

2026년 10월 3일 개정 · @Jin · v1(9/29) 대비 변경점은 신규수정 표시

원칙 한 줄

로고만 유광, 나머지 전부 무광. 단상자·용기 동일. 목적은 오프라인 매대와 SNS 폰 사진에서 “무광 코발트 위에 로고 하나만 빛을 받는” 대비를 만드는 것. 유광을 로고 외 요소에 쓰는 순간 빛이 분산되어 로고가 안 보입니다.

확정 사항 (재논의 없음)

브랜드 오너 확정안. 시안은 이 안에서만 변주합니다.

항목확정 내용
벤치마크수정단상자 전면 = Augustinus Bader / 단상자 측면 = RoC (비포·애프터 이미지 패널)
컬러코발트 블루 + 골드 계열 메탈. 로즈골드·코퍼 제외
마감수정단상자·용기·뚜껑 무광 / 로고(워드마크 + 심볼)만 유광. 제품명·카피·법정표기는 무광 인쇄
확장블루 라인 → 레드 라인. 메탈·레이아웃 공통
최우선 목표오프라인 매대와 SNS(폰 촬영)에서 무조건 보일 것 — 색 + 로고 빛반사까지

컬러 스펙

블루는 2728C / 2935C 두 후보로 샘플을 뽑고, 폰 촬영 결과로 1개를 확정합니다. 샘플 전까지 넘버는 바꾸지 않습니다.

구분지정비고
메인 블루 후보 APantone 2728C라프레리·다이슨 칫솔 톤. 폰에서 보라로 틀어질 위험
메인 블루 후보 BPantone 2935C보라기 적음. 폰 촬영 안정성 우선 후보
무광 단상자 인쇄 기준수정목표색보다 한 단계 밝게 — A·B 두 후보 모두 보정 칩을 뽑음2728C → 2727C, 2935C → 인쇄소가 같은 가이드에서 한 단계 밝은 칩 제안. 무광 처리 후 채도·명도 손실 보정
메탈 (골드)Pantone 871C 기준, 872C 이하 금지872C 이하는 웜조명에서 실버로 보임
핫포일 (로고)옐로 기운 유광 골드 (포일 업체 샘플북에서 선택)포일은 Pantone 넘버 없음. 캡 메탈과 나란히 대조 승인
제품명·본문신규화이트 (무광 인쇄)코발트 위 최고 대비. 골드 메탈릭 잉크는 무광 위에서 탁한 겨자색이 되므로 사용 안 함
레드 라인 (확장)Pantone 200C밝은 레드(185C)는 골드와 만나면 명절 선물세트 인상. 무광 보정 규칙 동일 적용
  • 인쇄는 전부 별색 지정. 코발트는 CMYK 색역 밖이라 프로세스 대체 불가 (견적서에 명시)
  • 라인 규칙: 메탈 871C 고정, 바디 컬러만 교체, 레이아웃·서체 100% 동일

부위별 마감 스펙

전 부위 무광, 로고만 유광. 유광 로고가 사진에서 “빛을 받는” 상태로 찍히도록 조건을 붙입니다.

부위마감구현 방식필수 조건
단상자무광코팅 판지(아이보리/SC) + 별색 + 무광 처리비코팅지 금지. 무광 필름 vs 무광 코팅액(OP/UV) 두 안 샘플 비교. 신규두 안 모두 그 위에 포일 접착 테스트(테이프 박리) 통과해야 채택
단상자 로고유광유광 골드 핫포일 + 형압수정워드마크·심볼 모두 포일 + 형압(엠보) 동시가공. 평평한 미러 포일은 정면 촬영 시 주변을 비춰 갈색·검정으로 죽음 → 엠보 단차가 어떤 각도에서도 하이라이트 한 줄을 잡게 함
용기무광불투명 외면 코팅안티핑거프린트 무광 UV. 테스터 유분 얼룩 방지
용기 로고유광핫스탬핑실크인쇄 골드 잉크 불가. 신규무광 UV 코팅과의 공정 순서·밀착 확인(크로스컷·알코올 러빙 테스트) 성적 첨부
뚜껑무광 계열알루미늄 헤어라인 + 새틴 아노다이징완전 무광 도장 금지(골드가 카키·겨자색). 새틴 = 반사는 있되 번쩍이지 않는 수준 → 로고보다 튀면 반려

단상자 레이아웃

앞은 럭셔리(AB), 옆은 증거(RoC). 매대에서는 전면이, 손에 들었을 때는 측면이 일합니다.

면레퍼런스구성기준
전면AB코발트 단색 70% 이상 + 골드 로고(유광) + 심볼 1개 + 제품명(화이트 무광)로고 캡하이트 10mm 이상 (1.5m 가독). 신규최소 SKU 단상자 다이라인에 먼저 앉혀 폭 확인 후 확정. 심볼 반복 패턴 금지
측면RoC큰 수치(예: 94%) + 비포/애프터 사진 + 클레임 1줄사진 영역은 흰 박스 안에 배치 또는 화이트 언더프린트. 수치는 화이트 무광 — 포일 금지
후면—전성분·법정 표기·바코드코발트 위 흰색 텍스트 최소 6pt. 바코드는 흰 박스 위 검정(코발트 위 직접 인쇄 시 스캔 불량)
  • 측면은 두 버전: A = 수치·비포애프터 / B = 성분 스토리. 수정론칭 초도 생산은 B로 확정, A는 시험 결과 수령 후 2차 생산부터 판 교체
  • SKU 전체 같은 코발트 1색. SKU별 톤 변주 금지 (페이싱 2~3개로 색 블록 형성)
  • 신규심볼은 AB 물결 원형 심볼과 형태 거리 확보 (원 + 동심 곡선 조합 지양)

판단 필터와 승인 절차

모든 시안·샘플은 아래 필터를 통과해야 승인. 하나라도 탈락하면 반려.

필터통과 기준
1. 오프라인 가시성화이트·베이지 위주 매대에서 1.5m 거리에서 브랜드 식별
2. SNS 폰 촬영 — 색아이폰·갤럭시 촬영 시 블루가 보라로 틀어지지 않음. 신규인스타그램 업로드 후 화면 캡처본 기준으로 판정 (재압축 후 색이 최종)
신규3. SNS 폰 촬영 — 빛반사정면 플랫 촬영에서 로고가 검게 죽지 않음 + 30~45° 기울였을 때 로고에 하이라이트가 잡힘. 용기·뚜껑에서 로고 외 부위가 로고보다 밝게 번쩍이지 않음
4. 레드 확장 호환같은 메탈·레이아웃에 200C 레드를 얹어도 성립
5. 생산 재현성판지·용기·캡·포일이 한 자리에서 같은 톤으로 보임. 용기 코팅 ΔE 2 이하 수정(기준 = 승인된 무광 단상자 칩, D50 측정)

샘플 승인 순서

  • 1. 무광 판지 샘플: 수정2727C·2728C·2935C·2935C 보정 칩 4종 × 무광 필름/코팅액 2안 + 골드 포일 2종(엠보 포함)
  • 2. 조명 3종 촬영: 약국 백색광(4,000~5,000K), 클리닉 웜조명(3,000K), 신규창가 자연광(SNS 언박싱 기본 환경)
  • 3. 폰 2기종 촬영: 아이폰·갤럭시, 보정 없이 원본 + 플래시 ON 1컷 + 인스타 업로드 캡처 비교
  • 4. 사진에서 가장 파랗게 남고 로고가 가장 빛나는 1안 확정 → 용기·캡·포일 동일 기준으로 대조 승인

금지 사항

  • 금지로즈골드·코퍼 메탈 (다이슨 칫솔·AB와 겹침, 레드 확장 불가)
  • 금지872C 이하 연한 골드 (웜조명에서 실버 → 라프레리와 겹침)
  • 금지코발트의 CMYK 프로세스 인쇄
  • 금지비코팅지, 소프트터치 라미
  • 금지완전 무광 도장 골드 캡
  • 금지용기 로고 실크인쇄
  • 금지신규로고 외 유광 요소 (부분 UV, 유광 제품명, 유광 수치, 홀로그램 포일)
  • 금지AB 3요소 동시 사용 (로열블루 병 + 구리 캡 + 화이트 단상자 물결 라인)
  • 금지실증 자료 없는 수치·비포/애프터 인쇄
