# turnova-tube-board 작업 규칙

## 디자인 룰 자동 반영 (대표 지시 2026-10-13)
- 디자인 기준은 `src/rules.js` 한 곳에 둡니다. 보드 시안, 조합 빌더, 경고 문구(룰 번호 [R##])가 모두 이 파일을 따릅니다.
- 대표님이 디자인 결정을 말하면 다음 순서로 진행합니다.
  1. `src/rules.js`에 룰을 한 줄 추가하거나 고칩니다. 번호·영역·룰·근거·날짜를 적습니다.
  2. 시안이나 경고 조건이 바뀌면 `src/combos.js`(렌더러·경고)와 `src/combos-data.js`(조합 목록)를 함께 고칩니다.
  3. `cd src && node render-combos.js && python3 build.py --repo && node build-strategy.js`로 다시 만들고, `index.html`·`strategy.html`을 갱신합니다.
  4. 같은 결정을 `guide-v5-patch.md`에도 적습니다. 가이드 v5 원본(PR #1 브랜치의 `turnova-guide-src/build_guide.js`)에 옮기는 것은 대표 허락 뒤에 합니다.
- 상위 가이드 v5 규칙이 우선합니다: 로열블루 1색, 코퍼 1색(골드 반려), 유광은 워드마크·심볼만, TRX-8™, 샤넬식 배치와 황금비.
- 공개 저장소이므로 타사 제품 이미지는 커밋하지 않습니다(`build.py --repo`가 자동으로 뺍니다).
