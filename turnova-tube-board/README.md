# TURNOVA 튜브 패키지 보드 (2026-10-12)

배리어크림(58ml 튜브)과 랩핑마스크(80ml 튜브)가 겹쳐 보이는 문제를 다룬 검토 보드입니다. 결론은 바디·라벨을 디자인 가이드 v5 그대로 두고 **체형과 캡으로 구분**하는 것입니다. 8각 캡은 금형 비용으로 보류했고, 기성 부자재만 씁니다. 대표 선택안(S00, 10/12): 배리어는 35Φ 슬림 + 코퍼 원형 스크류(화장대), 랩핑은 40Φ 와이드 + 블루 원형 원터치 + 코퍼 메탈 칼라(화장실), 필름밤은 원형 자 + 코퍼 뚜껑입니다.

- `strategy.html`: 캡 결정을 브랜딩·커머스·마케팅·비주얼 4개 팀 전략으로 키운 '왕복 리추얼' 전략(욕실 출발 → 화장대 도착). `node src/build-strategy.js`로 다시 만듭니다.
- `index.html`: 보드 본문. 공개 저장소라 타사 제품 이미지는 빼고 출처 링크만 남겼습니다. 이미지가 포함된 전체판은 비공개 아티팩트에 있습니다.
- `mockups/`: 시안 A/B/C와 캡 디테일 SVG. `node mockups/gen2.js`로 다시 생성합니다.
- 05 조합 갤러리: 배리어×랩핑 페어 18종과 필름밤 자 4종, 직접 섞어 보는 조합 빌더. 렌더러는 `src/combos.js`, 조합 목록은 `src/combos-data.js`이며, `node src/render-combos.js` 다음 `python3 src/build.py --repo`로 다시 만듭니다.
- `src/`: 보드 빌드 소스. `build.py`는 레퍼런스 이미지(`refs/`, 저장소 미포함)가 있어야 전체판을 만들고, `--repo` 옵션은 이미지 없는 판을 만듭니다.

시안은 가이드 규칙의 설계값으로 그린 콘셉트입니다. 정식 시안은 대표님 승인 뒤 `compose_label.py` 합성과 `measure_front.py` 실측으로 다시 만듭니다. 제품명은 모두 가칭입니다.

- 디자인 룰북: `src/rules.js`(R01–R14)가 시안·빌더·경고의 단일 기준입니다. 작업 순서는 `CLAUDE.md`, 가이드 v5에 옮길 내용은 `guide-v5-patch.md`에 있습니다.
- `spec.html` (10/13 통합본): 대표 견적서 엑셀 + 기성 품번 치수 + 장소 코드를 합친 발주 스펙. 라인업 4종(배리어 50ml · 랩핑 60ml · 필링 에센스 30ml · 필링밤 20g), 랩핑 3안(50Φ 60 / 50Φ 80 / 40Φ 80) 비교. 5종 기성품 치수도(같은 축척), 길이·캡 파이·캡 높이·토출구 표, 샘플 승인 체크리스트 12항목, 제조사·디자이너 전달 문안, 비주얼팀 검토. 대표 결정 10/13에 따라 튜브는 모두 기성 원터치, 배리어는 50ml입니다. 데이터는 `src/spec-data.js`, 빌드는 `node src/build-spec.js`입니다.
- `carton.html` (10/14): 단상자 시안. STE 몸통 + 샬롯 틸버리식 우측 2겹 날개(90° 열면 백보드), 닫힘·열림·펼친 칼선, 면별 배치(정면 브랜드 · 좌 상품 이미지 · 후 한·영 전성분 · 우측 날개 USP · 우측면 사용법), 규칙 C01–C16, 비주얼팀 검토. 데이터 `src/carton-data.js`, 빌드 `node src/build-carton.js --repo`(저장소용, 레퍼런스 사진 제외).
- 제품명(10/13 v4): DAILY BARRIER CREAM · LIFTING WRAPPING MASK · PEELING BOOSTING ESSENCE · PEELING BALM CREAM, 성분 코드 "with TERN-8™".
- 필링 에센스 30ml: 빌더와 05 섹션에 4가지 변형(E01–E04)이 있고, 기준은 블루 벌브 + 코퍼 PP 칼라 스포이드 병(R10)입니다. 앰플·세럼은 10/13 라인업에서 뺐습니다.
