06 · 대표 결정 필요

회신 전후로 정할 6가지

  1. 1. 랩핑 지름·용량 → 50Φ 60 mL (기준안 A)차별화가 가장 큽니다. 회신(10/24)에서 50Φ 기성 품번과 충전기 최소 길이가 확인되면 확정하고, 안 되면 40Φ 80 mL(C)로 갑니다.
  2. 2. 랩핑 80 mL 운영 → 50Φ 같은 캡으로 비교 견적 (B)같은 캡이라 나중에 대용량을 추가해도 부자재가 그대로입니다.
  3. 3. 배리어 코퍼 캡 공정 → PP 착색 기본, 증착·알루미늄은 비교 견적화장대 제품이라 증착이 가능하지만, 샘플 사진으로 차이가 클 때만 올립니다.
  4. 4. 로열블루 팬톤 → 칩 3개(2728C / 2736C / Reflex Blue)를 폰으로 찍어 비교실물보다 사진이 기준입니다.
  5. 5. 에센스 병 지름 → Ø33 (엑셀 기준), 없으면 가장 가까운 기성Ø36 기성(럭스팩 HB CU30)은 품번이 확인돼 있습니다.
  6. 6. 필링밤 부속 → 내부 디스크 포함, 스패출러 별도 견적스패출러를 넣으면 단상자 크기가 바뀝니다.
